github-actions
每日自動執行（GitHub Actions）

      

      

        
情報派報機本身只產生設定，不會自己執行。把下面兩個檔案放進一個 GitHub repo，就能讓它每天在雲端自動跑，不需要自己開電腦、不需要伺服器：

        
    
          
  1. 在 GitHub 建立一個新的 private repository（例如 daily-intel-bot）。
    2. 
          
  2. 把上方 Python 腳本另存為 daily_intel.py，連同下面的 requirements.txt 與 .github/workflows/daily-intel.yml 一併放進 repo 根目錄。
    3. 
          
  3. 到 repo 的 Settings → Secrets and variables → Actions，新增 3 個 Repository secrets：GEMINI_API_KEY、YOUTUBE_API_KEY（沒有 YouTube 關鍵字監控可留空）、GOOGLE_SHEETS_CREDENTIALS_JSON（貼上 Google 服務帳戶金鑰 JSON 的完整內容）。
    4. 
          
  4. 到 Actions 分頁確認 workflow 已啟用，可點「Run workflow」手動測試一次；預設每天台灣時間早上 7:00 自動執行。
    5. 
          
  5. 完成——之後金鑰只存在該 repo 的 Secrets 裡，不會經過情報派報機，也不需要任何人持續維護。
    6.
